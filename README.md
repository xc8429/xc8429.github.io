## 🛠 核心技術與專業能力

* **Windows 系統維護與維運**：具備 Active Directory (AD) 帳號與權限管理、Group Policy (GPO) 設定、機房 Server 運作監控與異常診斷能力。
* **PowerShell 與 Shell 自動化腳本**：擅長撰寫自動化腳本處理系統維護工作，能透過自動化備份與還原機制降低系統中斷風險。
* **網路架構與安全管理**：具備基本 Firewall 規則設定與除錯能力，擁有網路技能競賽經驗與 IT 駐點服務經驗。
* **IT Helpdesk 與技術支援**：熟悉企業端軟硬體故障排除、NAS 資料救援、系統權限調配與使用者問題快速回應
