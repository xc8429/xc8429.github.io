Windows Server AD Synology NAS ISO 資訊安全 最小權限原則

AD 網域與 NAS 權限管理：整合存取控制與 ISO 資安合規實務

將 Synology NAS 納入 Windows Active Directory 網域架構，透過集中式帳號與群組管理，落實符合機關 ISO 資訊安全規範的最小權限原則（Principle of Least Privilege）。

一、 專案背景與核心目標

在多部門協作的機關與企業環境中，若檔案伺服器（NAS）與網域帳號各自獨立管理，容易產生離職帳號未及時停用、跨部門資料誤存取以及權限盤點困難等資安風險。

  • 集中式身分驗證：將 Synology NAS 加入既有 Windows AD 網域，直接同步與讀取網域使用者（Domain Users）及安全性群組（Security Groups）。
  • ISO 資訊安全合規：依據組織資訊安全管理制度（ISMS）要求，建立清晰的權限分級與稽核軌跡。
  • 落實最小權限原則：使用者僅能存取執行業務所必需的共用資料夾與子目錄，阻絕非授權的橫向瀏覽與修改。

二、 系統整合與網域設定架構

[ Windows Server AD Domain Controller ] │ (LDAP / Kerberos 驗證與群組同步) ▼ [ Synology NAS (DSM 網域整合) ] │ ├── 讀取網域組織單位 (OU) 與安全性群組 ├── 啟用 Windows ACL 進階權限控管 └── 套用部門共用資料夾存取清單 (SMB/CIFS)

關鍵實作步驟

  1. DNS 與時間同步校準：將 NAS 的首選 DNS 指向 AD 網域控制站，並設定與 DC 同步的 NTP 時間伺服器，確保 Kerberos 驗證票證正常運作。
  2. 加入 Active Directory 網域：於 DSM「控制台 > 網域/LDAP」輸入網域名稱與網域管理員憑證，完成網域加入並驗證網域使用者與群組清單同步狀態。
  3. 停用本機非必要預設帳號：停用 NAS 預設 admin 帳號並改用獨立管理帳號，降低暴力破解風險。

三、 權限規劃矩陣與最小權限實作

採用 AGDLP（Account → Global Group → Domain Local Group → Permission） 概念設計權限結構，直接以「網域安全性群組」作為 NAS 共用資料夾與子資料夾 ACL 的授權對象，避免針對單一使用者零散設定權限。

共用資料夾名稱 管理部群組 業務/專案部群組 財務/人事群組 一般全體同仁
01_全機關公告與表單 讀取 / 寫入 唯讀 唯讀 唯讀
02_管理部行政專區 讀取 / 寫入 禁止存取 禁止存取 禁止存取
03_業務執行與專案檔 唯讀 (稽核) 讀取 / 寫入 禁止存取 禁止存取
04_財務與人事機密區 禁止存取 禁止存取 讀取 / 寫入 禁止存取
資安強化細節：啟用 SMB「對沒有權限的使用者隱藏共用資料夾（ABE, Access-Based Enumeration）」功能，並關閉高敏感資料夾的「一般使用者刪除檔案」權限（僅允許新增與修改，或由主管群組控管刪除），有效防範誤刪或勒索軟體擴散。

四、 ISO 資安稽核配合與維運成效

  • 人員異動即時連動：人員調動或離職時，僅需於 AD 端調整群組或停用帳號，NAS 存取權限即刻同步生效，消除權限殘留漏洞。
  • 完整存取日誌留存：啟用 Synology 日誌中心（Log Center）記錄 SMB 檔案讀取、寫入、刪除與權限變更軌跡，滿足 ISO 稽核對異常存取追蹤與定期權限清查（Access Review）的要求。
  • 權限盤點效率提升：透過群組化權限架構，定期向各部門主管產出權限清單進行覆核，大幅降低人工比對錯誤率。
