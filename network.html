NETWORK SECURITY POLICY

部門網路隔離

  • 禁止 客服與業務直接互通
  • 禁止 客服與資訊直接互通
  • 禁止 業務與資訊直接互通
  • 允許 各部門依權限存取指定服務

NAS 存取政策

  • 允許 客服連線 NAS
  • 允許 業務連線 NAS
  • 允許 資訊連線 NAS
  • 通訊協定：SMB / TCP 445
  • NAS 位址：192.168.40.20

NAS 內部另以帳號、群組及共享資料夾 ACL 控制各部門的檔案存取權限。

Core Layer 3 Switch 工作

  • 建立 VLAN 10 / 20 / 30 / 40
  • 設定各 VLAN 的 SVI Gateway
  • 啟用 IP Routing
  • 設定 ACL 控制部門間流量
  • 設定 Default Route 指向 Firewall

Firewall 工作

  • WAN 外部網路連線
  • NAT 網路位址轉換
  • 外部連線安全政策
  • 阻擋未授權外部連線
  • 回程路由指向內部 Core Switch

IP ADDRESS PLAN

  • VLAN 10｜客服：192.168.10.0/24
  • VLAN 20｜業務：192.168.20.0/24
  • VLAN 30｜資訊：192.168.30.0/24
  • VLAN 40｜伺服器：192.168.40.0/24
  • NAS：192.168.40.20

本架構為規劃示意。正式部署前仍須確認 DHCP、DNS、 AD、管理 VLAN、ACL 雙向規則與伺服器實際服務需求。
