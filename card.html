打卡提醒自動化系統

Windows BAT 自動化提醒專案紀錄

PROJECT DOCUMENTATION

01｜專案背景

為避免工作期間因忙碌而忘記上下班打卡， 因此希望利用 Windows 內建功能與批次檔， 建立一套不需要額外安裝軟體的打卡提醒系統。

本專案以 Windows 11 為環境， 採用 BAT 批次檔與 Windows 工作排程器的方向， 降低額外軟體安裝需求。

02｜設備與環境

作業系統Windows 11 64-bit
處理器Intel Core i5-8250U
記憶體8 GB RAM
顯示晶片Intel UHD Graphics 620
開發工具Windows CMD / BAT
儲存空間約 238 GB

03｜使用者需求

  • 上班時間 07:40 自動提醒。
  • 下班時間 16:30 自動提醒。
  • 使用黑色 CMD 視窗顯示文字提醒。
  • 不依賴 PowerShell、VBS 或第三方軟體。
  • 不希望 BAT 必須一直開啟才能等待提醒。
  • 希望電腦開機後即可具備自動提醒能力。

04｜實際執行與開發過程

第一階段：確認提醒方式

一開始嘗試使用 BAT 檔進行時間判斷， 並在指定時間顯示提醒訊息。

第二階段：調整執行方式

發現如果單純使用 BAT 迴圈持續檢查時間， 就必須讓 CMD 視窗一直保持執行。 這不符合希望背景等待、時間到才提醒的需求。

第三階段：改採 Windows 工作排程器

改以 Windows 內建的工作排程器作為時間觸發機制。 讓系統在指定時間啟動 BAT， 不需要額外安裝排程軟體。

第四階段：確認純 BAT 限制

純 BAT 可以透過 CMD 顯示文字， 但本身不具備在關閉後仍持續等待未來時間的能力。 因此必須由 Windows 工作排程器負責觸發。

06｜問題與解決方式

問題一：提醒視窗需求 希望不使用 PowerShell 視窗或額外彈窗工具。

解決：改用 CMD 文字視窗提醒。

問題二：BAT 必須持續執行 單純時間迴圈需要常駐執行。

解決：改由工作排程器定時啟動 BAT。

問題三：政府電腦限制 無法自由安裝額外程式。

解決：優先使用 Windows 內建工具。

問題四：自動啟動方式 希望不用每天手動開啟提醒程式。

解決：規劃開機後由系統排程負責執行。

07｜核心程式概念

BAT 可以透過以下指令顯示提醒訊息：

@echo off
chcp 65001 >nul
title 打卡提醒系統

echo ============================
echo       打卡提醒系統
echo ============================
echo.
echo 上班打卡時間到了！
echo.
pause

這段程式碼示範 CMD 文字提醒。 實際上線時，應依照不同觸發時間設定對應訊息， 再由工作排程器啟動。
